### Rules and input

Initial state: `stock={'camera':3,'mic':2}`; `reservations={}`. `reserve(id, items)` accepts only when every requested positive quantity is available. `items` contains no repeated products and all products exist. Rejection leaves both stock and reservations unchanged. Reservation IDs are new.

Operations: `R1=[('camera',2),('mic',3)]`, `R2=[('camera',2),('mic',1)]`.

### Current code

Process the supplied input in the displayed order.

```python
def reserve(stock, reservations, reservation_id, items):
    for product, quantity in items:
        if stock[product] < quantity:
            return False
        stock[product] -= quantity
    reservations[reservation_id] = dict(items)
    return True
```
