### Current code

Process the supplied input in the displayed order.

```python
def settle(rows, today, waiting_days):
    cutoff = today - waiting_days
    out = []
    for r in sorted(rows, key=lambda r: r["id"]):
        if r["captured_day"] < cutoff:
            fee = r["gross_cents"] * 125 // 10000
            out.append({"id":r["id"], "merchant":r["merchant"],
                        "net_cents":r["gross_cents"]-fee})
    return out
```
