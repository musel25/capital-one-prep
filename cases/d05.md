## Part 2 — Concrete technical exercise

The interviewer now supplies a specific input and a fixed contract. Follow these rules for the technical exercise even if you proposed a different product policy above. You are reviewing an existing implementation, which may violate the contract.

### A. Required behavior and supplied input

Purchases: p1 has category grocery and amount=5000; p2 has category travel and amount=8000; p3 has category grocery and amount=2000.

Refunds in order: f1→p1 amount=1000 posted; f2→p2 amount=3000 pending; f3→p1 amount=500 posted.

All amounts are positive integer cents. Only posted refunds reduce spending; attribute them to the original purchase category. Each ID is unique and all references are valid. No purchase is over-refunded in this input.

### B. Existing code — trace it as written

The supplied rows are passed in their displayed order. Do not assume this code implements the contract correctly.

```python
def net_by_category(purchases, refunds):
    totals = {}
    for p in purchases:
        totals[p["category"]] = p["amount"]
    for r in refunds:
        if r["state"] == "posted":
            purchase = next(p for p in purchases if p["id"] == r["purchase_id"])
            totals[purchase["category"]] += r["amount"]
    return totals
```

### C. Your technical tasks

First derive the **current output** by following the code exactly. Separately derive the **desired output** by applying the contract to the same input. Record intermediate state, then compare the two. Propose corrections and the requested extension on paper, without executing code.

1. Trace totals after each purchase/refund; give current and desired totals and total net spend.
2. Correct both defects and replace repeated linear lookup with an index. State time and space costs.
3. Implement **refundable(purchases, refunds, purchase_id)** returning original amount minus all posted refunds for that purchase, with minimum zero. Unknown purchase raises ValueError; pending refunds do not count. Return type is integer cents.
