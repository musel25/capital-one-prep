No purchase is over-refunded in this input. `posted` means completed; `pending` means not yet completed. `net_by_category` returns a dictionary of category → net integer cents, retaining categories whose net is zero. ### Current code

Process the supplied input in the displayed order.

```python
def net_by_category(purchases, refunds):
    totals = {}
    for p in purchases:
        totals[p["category"]] = p["amount"]
    for r in refunds:
        if r["state"] == "posted":
            purchase = next(p for p in purchases if p["id"] == r["purchase_id"])
            totals[purchase["category"]] += r["amount"]
    return totals
```
