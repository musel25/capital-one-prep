### Reglas y datos del ejercicio

Compras: p1 categoría grocery amount=5000; p2 travel amount=8000; p3 grocery amount=2000. Reembolsos en orden: f1→p1 amount=1000 posted; f2→p2 amount=3000 pending; f3→p1 amount=500 posted. Todos los importes son centavos positivos. Solo reembolsos posted restan; se atribuyen a la categoría de la compra original. Cada ID es único y todas las referencias son válidas; no hay sobre-reembolsos en esta entrada.

```python
def net_by_category(purchases, refunds):
    totals = {}
    for p in purchases:
        totals[p["category"]] = p["amount"]
    for r in refunds:
        if r["state"] == "posted":
            purchase = next(p for p in purchases if p["id"] == r["purchase_id"])
            totals[purchase["category"]] += r["amount"]
    return totals
```

1. Trace totals after each purchase/refund; give current and desired totals and total net spend.
2. Correct both defects and replace repeated linear lookup with an index. State time and space costs.
3. Implement **refundable(purchases, refunds, purchase_id)** returning original amount minus all posted refunds for that purchase, with minimum zero. Unknown purchase raises ValueError; pending refunds do not count. Return type is integer cents.
