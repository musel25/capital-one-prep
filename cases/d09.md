### Reglas y datos del ejercicio

Contrato: promoción válida para 100<=minute<160, amount_cents>=5000, new_customer=True y category='travel'. Reward bruto=5% por compra, floor a centavos, cap acumulado por cliente=300. Procesar en orden de tabla. Usado inicial U=100, V=0.

| id | customer | minute | amount_cents | new_customer | category |
|---|---|---:|---:|---|---|
| p1 | U | 100 | 5000 | True | travel |
| p2 | U | 159 | 6000 | True | travel |
| p3 | V | 160 | 7000 | True | travel |
| p4 | V | 120 | 5000 | False | travel |
| p5 | V | 140 | 5000 | True | grocery |

```python
def eligible(p):
    return (100 < p["minute"] <= 160
            and p["amount_cents"] > 5000
            and p["new_customer"] and p["category"] == "travel")

def awards(rows):
    return [(p["id"], p["amount_cents"] * 5 // 100)
            for p in rows if eligible(p)]
```
