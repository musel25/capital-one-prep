## Resultado razonado
Actual: **[answer, answer, answer, answer, search, search]**. Deseado sin presupuesto: **[human, answer, human, search, search, search]**. q1 exige escalamiento antes de mirar score; q3 idioma no soportado; q4 carece de fuente aprobada. q2 cumple igualdad0.80.

```python
def route(q):
    if q["sensitive"] or q["language"] not in {"en", "es"}:
        return "human"
    if q["confidence"] >= 0.80 and q["approved_source"]:
        return "answer"
    return "search"

def route_batch(rows, search_budget):
    out = []
    remaining = search_budget
    for q in rows:
        action = route(q)
        if action == "search":
            if remaining == 0:
                action = "defer"
            else:
                remaining -= 1
        out.append((q["id"], action))
    return out
```
Budget2: **[(q1,human),(q2,answer),(q3,human),(q4,search),(q5,search),(q6,defer)]**. Budget0: human,answer,human,defer,defer,defer. Vacío devuelve []; O(n) tiempo y O(n) salida. La automatización útil mide respuestas correctas/resolución, además de tasa de errores graves y calidad del escalamiento, no solo porcentaje de respuestas automáticas. Para calibración: conjunto evaluado, etiquetas, errores por subgrupo y relación entre scores y aciertos. Esta simulación no demuestra que un umbral concreto sea seguro.
