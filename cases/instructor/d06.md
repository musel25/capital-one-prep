## Resultado razonado
Etiqueta actual **'USD 0.00 available'** por un nombre de campo que no existe. valid_amount devuelve **[True, True, False, False, False, False]**: True es instancia de int. Deseado **[True, False, False, False, False, False]**.

```python
def label(payload):
    return f"{payload['currency']} {payload['available_cents']/100:.2f} available"

def valid_amount(value):
    return type(value) is int and value > 0

def preview(payload, amount):
    if not valid_amount(amount):
        return {"ok": False, "reason": "invalid"}
    if amount > payload["available_cents"]:
        return {"ok": False, "reason": "insufficient"}
    return {"ok": True, "remaining_cents": payload["available_cents"] - amount}
```
Etiqueta corregida **'USD 10.50 available'**. preview1050 → {'ok':True,'remaining_cents':0}; preview1051 → insufficient; previewTrue → invalid. Acceso obligatorio puede producir KeyError si el contrato no se cumple: una UI real debe presentar estado de error/carga, no inventar saldo0. Formatting usa división solo para presentación; la aritmética monetaria sigue en centavos. Preview es O(1) y no garantiza aceptación futura: el saldo puede cambiar antes de una operación real. Evidencia útil: respuesta de red, campo leído por UI y prueba de contrato. Métricas: discrepancia pantalla/API y errores de transferencia por saldo.
