Deseado: t1 inactive conserva (8000,2000,0); t2 ok produce (2000,2000,6000); t3 ok produce **(2500,2000,5500)**. history contiene t2 y t3 en ese orden.

```python
def transfer(accounts, history, tx_id, src, dst, amount):
    if not accounts[dst]["active"]:
        return "inactive"
    if accounts[src]["balance"] < amount:
        return "insufficient"
    accounts[src]["balance"] -= amount
    accounts[dst]["balance"] += amount
    history.append({"id": tx_id, "src": src, "dst": dst, "amount": amount})
    return "ok"

def account_history(history, account_id):
    out = []
    for tx in history:
        if tx["src"] == account_id:
            out.append({"id": tx["id"], "delta_cents": -tx["amount"]})
        elif tx["dst"] == account_id:
            out.append({"id": tx["id"], "delta_cents": tx["amount"]})
    return out
```
Para A: **[{'id':'t2','delta_cents':-6000},{'id':'t3','delta_cents':500}]**. Para B: []. Suma de saldos permanece 10000; una operación rechazada no aparece como completada.
