## Part 2 — Concrete technical exercise

The interviewer now supplies a specific input and a fixed contract. Follow these rules for the technical exercise even if you proposed a different product policy above. You are reviewing an existing implementation, which may violate the contract.

### A. Required behavior and supplied input

`amount_cents >= 0`. The rate is 2%. Compute the gross reward as `floor(amount_cents * 2 / 100)` for each purchase. The cap is 100 cents per `(customer, month)`. Only posted purchases qualify. Process purchases in the supplied order. Initial usage: `{('U','2026-10'): 85}`. Every row belongs to customer U.

| id | month | amount_cents | state |
|---|---|---:|---|
| r1 | 2026-10 | 149 | posted |
| r2 | 2026-10 | 800 | posted |
| r3 | 2026-11 | 150 | posted |
| r4 | 2026-11 | 999 | pending |

### B. Existing code — trace it as written

The supplied rows are passed in their displayed order. Do not assume this code implements the contract correctly.

```python
def award(rows, used):
    out = []
    for r in rows:
        if r["state"] != "posted":
            continue
        key = (r["customer"], r["month"])
        raw = round(r["amount_cents"] * 2 / 100)
        given = min(raw, 100)
        used[key] = used.get(key, 0) + given
        out.append((r["id"], given))
    return out
```

### C. Your technical tasks

First derive the **current output** by following the code exactly. Separately derive the **desired output** by applying the contract to the same input. Record intermediate state, then compare the two. Propose corrections and the requested extension on paper, without executing code.

1. Trace exact current awards and used; compare with the contract. Python round(2.98)=3 and round(3.0)=3.
2. Correct rounding and the cap without using floating-point money.
3. Implement **remaining(used, customer, month)** returning nonnegative available reward cents with no mutation, including absent keys and a corrupted stored value of 130. State whether clamping repairs the historical accounting.
