## Part 2 — Technical exercise

For this part, use the following contract, even if your product proposal was different.

### Rules and input

This function receives an already-available batch of purchases. Select alerts within that batch; do not predict future purchases or design a real-time notification system for this technical task.

- Only `posted` purchases with `amount_cents >= 2000` are eligible.
- For each merchant, keep the eligible row with the greatest `(minute, id)`.
- Return the selected rows in ascending `(minute, id)` order.
- Do not modify the input. IDs are unique and comparable as strings.

| id | merchant | minute | amount_cents | state |
|---|---|---:|---:|---|
| a1 | M1 | 540 | 2500 | posted |
| a2 | M2 | 480 | 3000 | pending |
| a3 | M1 | 600 | 1800 | posted |
| a4 | M2 | 540 | 2200 | posted |
| a5 | M3 | 540 | 2000 | posted |
| a6 | M1 | 660 | 2400 | posted |

### Current code

Process the supplied input in the displayed order.

```python
def alerts(rows):
    candidates = [r for r in rows
                  if r["state"] != "declined" and r["amount_cents"] >= 2000]
    seen, out = set(), []
    for r in sorted(candidates, key=lambda r: (r["minute"], r["id"])):
        if r["merchant"] not in seen:
            out.append(r)
            seen.add(r["merchant"])
    return [r["id"] for r in out]
```
