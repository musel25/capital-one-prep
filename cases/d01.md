### Reglas y datos del ejercicio

Contrato: solo compras **posted** con amount_cents >= 2000; por merchant conserva la candidata con mayor (minute, id); devuelve las elegidas en orden ascendente (minute, id). No modifiques la entrada. Los IDs son únicos y comparables como strings.

| id | merchant | minute | amount_cents | state |
|---|---|---:|---:|---|
| a1 | M1 | 540 | 2500 | posted |
| a2 | M2 | 480 | 3000 | pending |
| a3 | M1 | 600 | 1800 | posted |
| a4 | M2 | 540 | 2200 | posted |
| a5 | M3 | 540 | 2000 | posted |
| a6 | M1 | 660 | 2400 | posted |

El código recibe los diccionarios de la tabla en ese orden:

```python
def alerts(rows):
    candidates = [r for r in rows
                  if r["state"] != "declined" and r["amount_cents"] >= 2000]
    seen, out = set(), []
    for r in sorted(candidates, key=lambda r: (r["minute"], r["id"])):
        if r["merchant"] not in seen:
            out.append(r)
            seen.add(r["merchant"])
    return [r["id"] for r in out]
```
