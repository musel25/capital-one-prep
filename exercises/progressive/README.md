# Progressive coding: merchant events

Original fictional array/dictionary practice. It is not an employer question.
Use one solution throughout; new stages extend its requirements.

1. Open only this attempt folder in your editor.
2. Run `uv sync`. No server is needed.
3. Read STAGE_1.md. Predict the examples, explain your approach and implement
   `summarize(events)` in solution.py.
4. Run `uv run pytest -q tests/test_stage1.py`.
5. After explaining stage 1 (or when its time expires), reveal stage 2 on the
   website and read STAGE_2.md. Run stages 1 and 2 together.
6. Reveal stage 3, read STAGE_3.md and run `uv run pytest -q`.

The starter deliberately raises NotImplementedError. These public tests are
examples, not proof of general correctness: add your own boundary tests.
Later stage files are present but should stay closed until that stage.
You can practice manually or with an authorized AI assistant. State your own
hypothesis and expected result first; inspect generated code and test it.
If using AI, record one accepted or rejected suggestion and your evidence.

The 75-minute schedule is: orient 5, stage 1 15, stage 2 15, stage 3 20,
regression checks 10, explanation 10. Keep partial progress when time expires.
Record completed stages and help used; an unfinished later stage does not erase
earlier work. Save notes here or in the website's My attempt tab.

There is no external `practice.py check` for this exercise. Its checks are
the local pytest commands above. To start again, run the progressive launcher
from the repository root; it creates another folder and preserves this one.
