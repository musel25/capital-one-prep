## Learn

Think about the edge. Is 60 a pass when you need "60 or more"?
Use `>=` for "bigger or equal". `>` does not include the number itself.

## Your task

Read a test score from 0 to 100. A score of **60 or more** passes.

| Input | Your program shows |
| --- | --- |
| `75` | `You passed!` |
| `59` | `Try again` |
| `60` | `You passed!` |
