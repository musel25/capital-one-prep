## Learn

Each `input()` reads the **next** line. Two `input()` calls read two lines.

```python
first = input()
second = input()
```

If the input is

```text
red
blue
```

then `first` is `"red"` and `second` is `"blue"`.

## Your task

Read two whole numbers, one on each line. Show the sum like this:

| Input | Your program shows |
| --- | --- |
| `3` and `4` | `3 + 4 = 7` |
| `10` and `20` | `10 + 20 = 30` |

Tip: `print(a, "+", b, "=", a + b)` puts spaces between the parts.
